# NuclearDiffusion Studio - frontend

Next.js 16 app for the inference console. See the repository [README](../README.md) for the overview and [`../docs/API.md`](../docs/API.md) for the `/api/generate` contract.

```bash
npm install
npm run dev      # http://localhost:3000, mock inference by default
npm run check    # typecheck, lint, unit tests, E2E
```

Configuration lives in `.env.local`; see [`.env.example`](.env.example).
